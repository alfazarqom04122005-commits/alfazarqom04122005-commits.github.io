# Asri Collection — Supabase

Dokumentasi dan bahan kerja untuk backend Supabase Asri Collection.

## Cakupan
- Database schema, migrations, dan SQL
- Row Level Security (RLS), grants, dan policies
- Supabase Edge Functions
- Storage, RPC, serta kontrak transaksi
- Catatan audit dan verifikasi

## Batasan
- Folder ini untuk dokumentasi dan source code yang dikelola melalui GitHub.
- Jangan menyimpan secrets, service-role keys, API keys, atau kredensial di repository.
- Perubahan database dan deployment memerlukan persetujuan terpisah.

## Struktur yang disarankan
- `migrations/` — migrasi SQL yang ditinjau
- `functions/` — source Edge Functions
- `docs/` — audit, requirement, dan catatan teknis
